# 首次自适应高度

省略 `window.height` 时，窗口按确定的宽度完成首次布局，再计算整个窗口高度。首次显示后锁定尺寸，后续内容更新、媒体加载、隐藏和重新显示均复用尺寸；溢出正文通过滚动访问。

| 类型 | 默认宽度 | 自动高度范围 | 测量不可用时的回退高度 |
| --- | ---: | ---: | ---: |
| dialog | 440 | 160–720 | 300 |
| notify | 360 | 120–480 | 220 |

单位均为逻辑像素。默认尺寸可通过 [Host 配置文件](configuration.md) 调整。自动高度的上限还受目标显示区域减去上下边距（默认各 16）的限制，小屏幕限制优先于最小高度。显式数字和百分比高度继续遵循原规则，不应用自动高度边界。

## 职责与数据

- `placement::WindowLayout` 保存宽度／高度策略、显示环境、首选高度及锁定标记。它不持有内容快照，不操作窗口，也不修改调用方请求。
- `host/coordinator.rs` 为每个原生请求窗口保存一份 `WindowLayout`；创建、拟合、显示和显示环境变化均使用它生成尺寸。缓存实际物理尺寸的 `sizes` 仅用于可见通知的整栈排布与健康检查。
- `ui/src/window-sizing.js` 在测量样式下读取内容根节点的自然高度及应用外部留白。它不决定高度边界或操作原生窗口。
- `host/windows.rs` 负责执行原生尺寸和位置调整；协调器在调整后更新 Windows 裁剪区域，最终揭示由既有显示流程完成。

请求中的缺省高度保留为 `None`。`Request::default_window_size` / `window_size` 返回的是准备或回退几何，不代表自动高度窗口的最终尺寸。

## 准备与显示

1. 协调器确定目标显示环境及宽度，创建隐藏／遮蔽窗口，并保存布局状态。
2. 前端同步创建文字、表单和固定媒体容器。图片与图标异步解码；图表保留原有的限时编译和语义校验。字体和布局帧等待仍有超时边界。
3. 未指定高度且尚未锁定时，前端测量内容并调用 `fit_window(revision, measurement)`，其中测量值包含 CSS 宽度和自然高度。
4. 协调器只接受当前 revision 且处于 `preparing` / `ready` 的测量。宽度与布局不匹配时要求重试；前端最多重试三次，之后请求使用回退高度。缺少可测量根节点或非法高度同样使用受限回退值。
5. 应用最终尺寸及原生裁剪区域后，前端等待有界布局帧，再调用原有 `ui_ready(revision)`。准备期间收到更新时，以最新版本重新完成这一流程。
6. `ready` 窗口满足显示条件后锁定布局，通知前端停止测量，再揭示并提交 `shown`。只有此时开始实际展示计时。

通知队首在没有其他准备窗口且未达到数量上限时可以提前隐藏准备。是否能放下，在最终尺寸确定后判断；空间不足保持 `ready` 等待，后续通知不能越过。准备超时沿用原有 15 秒看门狗；`ready` 等待空间不消耗准备或展示时长。

显示后即使收到额外测量，也不能改变首选高度。隐藏或暂时停放不删除布局状态，窗口销毁时清理。工作区／DPI 变化仍按现有通知流程重新应用环境约束和整栈排布，使用保存的首选高度，不重新按内容测量；屏幕临时变小后可恢复原有尺寸。

## 模板与媒体

模板在自然布局根节点上声明 `data-popu-size-root`。测量状态由 `html.popu-measuring` 表示；此时根节点应使用自然高度，解除固定高度、正文 flex 填充及依赖视口高度的限制。自然布局应包含标题、时间戳、正文、动作区、边框和内边距。`#app` 的上下留白由测量模块单独计入，模板不再增加外边距。

内置模板使用稳定滚动条占位，使测量和正文溢出时的排版宽度相同。正文垂直居中产生的剩余空间不计入自然高度。未声明根节点的旧外部模板使用受限回退尺寸；要求精确尺寸时也可显式提供窗口高度。

内置模板将标题和时间戳固定在正文滚动区上方，动作区保留在窗口底部。正文溢出时可通过键盘或滚轮独立滚动。标题单行显示，过长时以省略号收尾，悬停提示展示完整标题。图表预留容器也支持内部滚动，以完整访问超过容器尺寸的分面、拼接等组合图表。

图片在解码前预留 `block.height` 指定的容器高度，默认 320；加载中、成功和失败的容器高度相同，图片等比放入容器。标题和说明文本在容器外参与正常排版。图表使用固定容器高度，默认 220；图表内部渲染和交互不改变容器。图标固定为 28×28。图片解码失败显示容器内错误，图表语义错误继续沿用原有渲染失败处理。

历史详情继续等待媒体渲染后确认阅读；请求窗口可在图片解码前确定尺寸并显示。媒体渲染是否完成与布局是否已确定分别处理。

## 验证

纯几何测试覆盖上下界、显示前收缩、显示后锁定、非法测量、过期宽度、显式高度、DPI 与小屏幕。浏览器测试在浅色／常规 DPI 和深色／高 DPI 下覆盖首次拟合、最大高度滚动、按钮可见、仅指定宽度、更新后固定尺寸、图片占位及旧模板回退。原生集成测试使用独立 IPC 端点验证实际窗口尺寸、通知队列与保留窗口重新显示。
